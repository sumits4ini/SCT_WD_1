About This Project

This project was made during my internship at SkillCraft Technology. The goal was to build a landing page with a responsive navigation menu that changes its look when the user scrolls and includes hover effects.

I learned how HTML, CSS, and JavaScript work together to create a complete webpage that looks good on phones, tablets, and desktops.

Responsive Design HTML5 CSS3 JavaScript Interactive Navigation

Features

📌

Fixed Navigation Menu

The navbar stays at the top while you scroll so the links are always visible.

🎨

Scroll-Based Effects

The navbar background and shadow changes when you scroll down the page.

✨

Hover Animations

Links and buttons have smooth color and movement effects on hover.

📱

Mobile Responsive

On small screens a hamburger menu is shown and the layout adjusts automatically.

🖱️

Smooth Scrolling

Clicking any nav link scrolls smoothly to that section of the page.

💻

Modern UI

Clean layout with nice colors and spacing that looks presentable and professional.
