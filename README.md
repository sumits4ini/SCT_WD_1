# 🌐 Responsive Landing Page

A modern and responsive landing page developed as part of the **SkillCraft Technology Web Development Internship**.

## 📌 Project Overview

This project focuses on creating an interactive navigation menu that remains fixed at the top of the page and changes its appearance when the user scrolls or hovers over menu items. The website is fully responsive and provides a smooth user experience across desktop, tablet, and mobile devices.

## ✨ Features

- Fixed Navigation Bar
- Scroll-Based Navbar Effects
- Interactive Hover Animations
- Smooth Scrolling Navigation
- Fully Responsive Design
- Modern UI/UX Layout
- Mobile-Friendly Interface
- Clean and Organized Code Structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
